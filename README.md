## 읽는 순서

1. **처음 온 사람**: 기획서 §1(성공 조건) → IA 문서 §1~2 → 화면설계
2. **목업 만드는 사람**: `P-01-홈.md`의 인터랙션 배정표 + 기획서 §6(디자인 원칙·레퍼런스) 필독
3. **개발하는 사람**: **PRD §4~§11(요구사항)** → §15(ID 색인) — 여기 없는 기능은 만들지 않는다
4. **검수하는 사람**: **PRD §1.2(성공 판정) + §3.2(릴리스 게이트)**
5. **8/12 미팅 준비**: 기획서 §14 + **PRD §14.2(신규 결정 D1~D5)** + 백로그 §4

## 절대 규칙 (요약)

- **딸깍 금지** — 섹션마다 다른 인터랙션, 의도적 정지 구간 포함
- **가격·저렴함 소구 금지** / 근거 없는 수치 금지
- **CTA는 지정된 5곳만** — 버튼 하나가 전환을 죽인 실측 사례
- **리드는 pluug** — 우리 DB에 저장하지 않음
- **범위는 17화면** — 여기 없으면 만들지 않고 백로그에 먼저 적는다

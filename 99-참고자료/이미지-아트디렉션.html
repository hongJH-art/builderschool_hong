이미지는 무엇을, 어떻게 넣을 것인가

클라이언트의 말: "에셋의 퀄리티가 홈페이지의 퀄리티를 좌우한다." 회사 홈페이지는 사실상 텍스트+이미지뿐이다. 우리는 신생 브랜드라 실적 사진·팀 사진이 없다 — 그래서 '무엇을 찍을까'가 아니라 '무엇을 만들까'가 이 문서의 주제다. 아래 처리 예시는 전부 이 페이지 안에서 실제 CSS로 렌더된 것이므로, 그대로 목업에 이식하면 된다.

Strategy — 쓸 수 있는 이미지 5타입

이미지 타입별 전략과 딸깍 위험도

신생 브랜드의 제약(실적·팀 사진 없음)을 전제로, 실제로 조달 가능한 것만 다룬다.

A. UI 실물 스크린샷 + 프레임주력 — 전체의 70%딸깍 위험 없음

우리가 만든 결과물의 스크린샷을 브라우저·디바이스 프레임에 넣은 것. 개발 외주 사이트에서 유일하게 "증거"가 되는 이미지다. Linear·Vercel·MetaLab이 사이트 전체를 이것만으로 만든다. 지금 만든 목업 자체가 첫 소재다.

조달이번 목업 캡처 + 똑개 실적 스크린샷(Q4 확정 후)
B. 통일 규격 썸네일 컴포지션Work 전용 규격딸깍 위험 없음

스크린샷을 통일된 배경색 + 동일 기울기 + 동일 그림자로 조판한 카드 커버. Behance 케이스 커버·Pentagram 그리드의 문법. 리서치 결론: "모든 타일이 같은 무게를 가질 때 다양함이 '범위'로 읽히고, 다르면 '난잡함'으로 읽힌다."

C. 현장·사물 사진 (톤 보정 필수)보조 — 20%보정 없으면 스톡 티

키보드 위의 손, 화이트보드, 회의 노트, 모니터 앞 뒷모습 같은 클로즈업·부분 컷. 얼굴 정면 컷은 쓰지 않는다(인물 미확정 + 스톡 티). 반드시 그레인+틴트 보정으로 팔레트에 묶는다 — 2026 트렌드 리서치에서도 "필름 그레인 + 웜 뉴트럴 톤"이 에디토리얼 기준.

D. 산출물 문서 스냅샷차별화 무기딸깍 위험 없음

기획서 표지, IA 다이어그램, 검수 체크리스트를 문서 실물처럼 조판한 이미지. "일하는 방식"이 소구점인 우리에게는 포트폴리오보다 강한 증거다 — 프로세스를 말이 아니라 산출물 실물로 보여준다.

E. 추상 그라디언트 · 3D · AI 생성 이미지원칙 금지

"AI 딸깍 금지"가 1순위 요구인 프로젝트에서 AI 티가 나는 이미지는 자살골이다. 추상 3D 블롭, AI 생성 일러스트, 의미 없는 그라디언트 카드가 대표적 딸깍 신호. 예외는 둘뿐 — ① S1 배경의 흐린 그라디언트(장식이 아니라 조명 역할) ② 노이즈·그레인 텍스처(사진 보정 재료). 이 둘도 콘텐츠 이미지로는 쓰지 않는다.

① 브라우저 프레임 — 타입 A의 기본 규격

스크린샷을 날것으로 두지 않고 브라우저 크롬(신호등 3개 + URL바)에 넣는다. URL바에 실제 주소를 넣으면 "진짜 배포됐다"는 신호가 된다.

규격: 코너 12px · 보더 1px rgba(ink,.08) · 그림자 0 24px 48px -12px rgba(ink,.28) · 배경은 팔레트 파생 그라디언트(채도 낮게).

레퍼런스: Linear 릴리스 노트, Raycast 홈, Arc 브라우저 사이트 — 셋 다 "스크린샷+프레임+은은한 글로우"가 전부다.

② Work 썸네일 규격 — 타입 B의 통일 조판

전 카드 공통: 어두운 단색 배경 + 좌상단 카테고리(모노폰트) + 스크린샷 -4° 기울여 우하단 크롭 + 라임 글로우 1곳.

배경색만 프로젝트마다 다르게(다크 그린·다크 네이비·다크 브라운 등 6색 순환), 구도는 절대 바꾸지 않는다 — "같은 프레이밍이 다양함을 범위로 읽히게 한다."

레퍼런스: Behance 케이스 커버 상위작들, Pentagram 그리드, Artboard Studio 템플릿.

③ 사진 톤 보정 — 타입 C를 팔레트에 묶는 법

스톡 사진을 원본 그대로 쓰면 100% 티가 난다. 두 가지 처리 중 하나를 사이트 전체에 일괄 적용:

듀오톤: grayscale(1) sepia(.5) hue-rotate(28deg) saturate(2.4) — Spotify Design이 정착시킨 문법. 어떤 출처의 사진이든 우리 색이 된다.

모노+그레인: grayscale(.9) + SVG 노이즈 오버레이 mix-blend-mode:overlay — 2026 트렌드 리서치의 "필름 그레인·아날로그 질감" 방향. 흑백이라 인물·장소가 익명화되는 부수 효과도 있다.

→ 권고: 모노+그레인을 기본으로, 라임 듀오톤은 커버 1~2곳만.

④ 산출물 문서 스냅샷 — 타입 D, 우리만의 무기

기획서·IA·검수 체크리스트를 흰 종이 질감 + 1.5° 기울기 + 부드러운 그림자로 조판. 라임 하이라이트를 문서 안에 한 곳만.

S3 "일하는 방식" 각 스텝 카드에 이 규격으로 실제 산출물을 깔면, "체계적으로 일한다"는 주장이 실물 증거로 바뀐다. 소재는 이미 있다 — 이 프로젝트의 기획서·IA 문서가 그것이다.

레퍼런스: Stripe Docs 카드, Notion 템플릿 갤러리의 문서 프리뷰.

아래는 전부 실제 사진(Unsplash — 상업 사용 무료, 핫링크 검증 완료)이다. 카드마다 어디에 들어가는지(라임 배지), 왜 이 느낌인지, 나중에 직접 찍을 때의 가이드를 달았다. 상단의 톤 버튼을 누르면 26장 전체에 우리 보정 규격(모노+그레인 / 라임 듀오톤)이 실시간 적용된다 — "아무 사진이나 가져와도 우리 톤이 되는지"를 이 자리에서 확인할 수 있다.

Group 1 — 화면·글로우·다크

모니터가 주인공인 컷 → S1 히어로 · S3/S8 다크 섹션

개발 회사의 "일하는 장면"은 얼굴이 아니라 화면과 빛이다. 어두운 공간 + 화면 글로우가 우리 다크 섹션(S3·S8)과 자연스럽게 이어진다.

BESTS1 히어로S3
멀티 모니터 앞 뒷모습

얼굴 없이 "일"만 보이는 구도. 익명이라 모델 섭외 없이 우리 팀 아무나 찍어도 대체 가능. 화면 글로우가 조명 역할.

역광 없이 화면 빛만. 뒤에서 어깨 너머로, 주변 조도 낮추고 1/60s 내외.
S3 배경S8
코드 화면 클로즈업

다크 섹션의 배경 텍스처로 흐리게 깔기 좋은 컷. 코드 내용이 읽히면 안 됨(우리 코드로 교체하거나 블러).

우리 실제 에디터 화면을 어둡게 캡처 — 스톡 대신 실물이 정답인 컷.
S4Insight 커버
데스크 셋업 정면

정돈된 셋업 = "체계"의 시각 번역. S4(검증 체계) 옆 정적 1컷으로 어울림.

데스크 위 물건 3개 이하로 치우고 정면 수평. 화면엔 우리 사이트 띄우기.
S8
화면 글로우 무드

어둠 속 화면 빛 — S8(유튜브 다크 섹션)의 썸네일 사이 분위기 컷. 라임 듀오톤 적용 시 브랜드 컷이 됨(상단 버튼으로 확인).

불 끄고 화면 밝기 최대, 노출 -1EV. 초점은 화면 모서리에.
Insight 커버
얕은 초점 모니터

보케(초점 흐림)가 만드는 여백 — 텍스트를 얹을 자리가 있는 컷. Insight 커버처럼 제목이 올라가는 곳에.

조리개 최대 개방(F1.8~2.8), 피사체와 1m, 배경과 2m 이상.
보류
(반례 겸 후보) 야간 후드 작업

"해커 클리셰" 경계선의 컷. 몰입감은 좋지만 후드+어둠 조합은 수주용 사이트에서 불안 신호가 될 수 있음 — 팀 판단 필요.

쓴다면 후드 대신 일반 복장으로 재현하고 조도만 가져오기.
Group 2 — 손·키보드 클로즈업

손이 주인공인 컷 → S3 스텝 · Insight 커버

얼굴 없는 노동의 클로즈업 — 토스·우아한형제들이 쓰는 바로 그 문법. 모노 보정 시 익명화되어 어떤 팀원 손이든 소재가 된다.

BESTS3 개발 스텝
타이핑 클로즈업 (근접)

S3 "개발" 스텝 카드의 배경 1순위. 프레임에 손+키보드만 — 정보가 아니라 리듬이 찍힌 컷.

측면 45°, 손목까지만. 셔터 1/125s로 손가락 약간의 블러 허용 — 정지보다 생동감.
S3Insight 커버
다크 키보드 + 손

어두운 배경이라 다크 섹션에 이질감 없이 얹힘. 듀오톤 적용 시 가장 예쁘게 변하는 컷 중 하나(버튼으로 확인).

검은 데스크매트 위에서 탑다운 약간 비껴서.
Insight 커버
밝은 톤 타이핑

밝은 배경 버전 — 라이트 지면(Insight 목록)의 커버로. 같은 소재를 밝음/어둠 두 톤으로 확보해두면 지면에 맞춰 골라 쓴다.

창가 자연광, 오전 10~11시. 흰 데스크 위.
S5 hover
미니멀 키보드 탑다운

여백이 많아 소형으로 잘라 써도 살아있는 컷 — S5 매칭 카드 hover 시 등장하는 작은 이미지 용도.

완전 탑다운(90°), 키보드를 프레임 1/3에 배치.
Insight 커버
이미 흑백인 작업 컷

원본부터 흑백 — 우리 모노+그레인 규격의 완성형 미리보기. 이 느낌이 사이트 전체 사진 톤의 목표점이다.

촬영은 컬러로 하고 보정에서 흑백 — 원본 보존.
S2 분위기
노트북 작업 미드샷

손보다 조금 넓은 프레임 — 클로즈업만 반복되면 단조로우니 중간 거리 컷을 사이에 끼워 리듬을 만든다.

테이블 반대편에서 눈높이보다 낮게. 얼굴은 프레임 밖.
Group 3 — 기획·화이트보드·문서

과정이 보이는 컷 → S3 기획 스텝 · S4 검증 체계

"일하는 방식"이 소구점인 우리에게 가장 전략적인 그룹. 완성물이 아니라 과정의 물증을 찍는다.

BESTS3 기획 스텝
화이트보드 앞 두 사람

S3 "기획" 스텝의 정답 컷. 손+보드+마커만 보이고 얼굴은 없거나 옆모습 — 협업이 연출 없이 찍힘.

보드에 실제 우리 IA 다이어그램을 그려놓고 촬영 — 소품이 곧 콘텐츠.
S3Insight 커버
보드에 쓰는 순간

단독 버전 — 마커 쥔 손과 판서 궤적. "설계한다"는 동사가 찍힌 컷.

판서 내용이 3단어 이상 읽히게. 우리 용어(IA·검수·슬러그)면 더 좋다.
S3 검수 스텝
종이 위 체크·필기

S3 "검수" 스텝용. 체크리스트에 펜 얹힌 구도 — 문서 스냅샷(타입 D)과 실사진의 중간 지점.

실제 검수보고서 출력물 + 펜. 탑다운, 문서 기울기 1~2°.
S4 배경
빈 보드·여백

정보 없는 미니멀 컷 — 정지 섹션(S4)의 숨 쉬는 배경. 콘텐츠와 경쟁하지 않는 이미지도 필요하다.

벽·보드·책상 모서리 같은 "아무것도 아닌 곳"을 정면 수평으로.
Insight 커버
노트+펜 플랫레이

Insight "일하는 방식" 카테고리 커버로 반복 사용 가능한 시리즈 규격 후보. 같은 구도로 소품만 바꾸면 커버가 계속 나온다.

탑다운, 좌상단 여백 40% 비우기(제목 자리). 소품 2개 이하.
Insight 커버
노트 시리즈 변주

위 컷과 짝 — 커버 시리즈의 2번째 변주. 시리즈감이 곧 브랜드 일관성.

같은 조명·같은 각도 유지, 노트 색만 교체.
Group 4 — 협업·공간

사람이 배경인 컷 → S4 신뢰 · 회사 소개류

얼굴 정면은 여전히 금지. 흐릿한 사람 + 선명한 공간이 "실제로 일하는 조직"을 증언한다.

BESTS4
흑백 오피스 군상

원본부터 흑백 — 모노 규격과 완벽 일치. 사람이 있는데 아무도 특정되지 않는, 우리가 원하는 딱 그 거리감.

유리벽 너머·계단 위 등 한 겹 거친 시점에서. 움직임 블러 환영.
S4
채광 좋은 작업 공간

공간이 주인공, 사람은 소품 — "환경이 갖춰져 있다"는 신호. 밝은 지면(S4)에 어울림.

광각으로 창을 프레임에 크게. 오후 3~4시 사광.
보조
테이블 협업 (경계선)

스톡 티 경계선의 컷 — 쓴다면 반드시 모노 보정 + 소형 배치로. 원본 그대로 크게 걸면 바로 스톡처럼 보인다(버튼으로 비교해보라).

직접 찍을 땐 "회의하는 척" 금지 — 실제 회의 중에 문가에서 한 컷.
Group 5 — 데스크·기기 정물

기기 정물 컷 → P-03 상세 · 스크린샷 합성 베이스

화면이 비어있는 기기 컷은 우리 UI 스크린샷을 합성해 넣는 베이스로 쓴다 — 찍은 사진이 목업 프레임이 되는 것.

P-03 히어로
데스크 위 모니터 정물

화면에 우리 결과물을 합성하면 Work 상세 히어로가 된다. 브라우저 프레임(CSS)보다 물성 있는 버전.

화면 정면 수평 필수(합성 왜곡 방지). 반사 없는 각도.
P-03 본문
노트북 사선 정물

본문 중간의 호흡 컷 + 합성 베이스. 사선 각이라 화면 합성 시 원근 변형 필요 — shots.so가 자동 처리.

45° 사선, 자연광. 키보드에 살짝 초점.
S7 인접
흑백 기기 정물

읽는 영역(S7 인접) 옆에 놓아도 시선을 뺏지 않는 조용한 컷. 이미지가 필요하지만 조용해야 하는 자리용.

그림자를 부드럽게(커튼 확산광). 대비 낮게 찍고 보정에서 올리기.
